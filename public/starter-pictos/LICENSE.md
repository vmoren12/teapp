# Llicència dels pictogrames inclosos

Els pictogrames d'aquesta carpeta són d'ARASAAC:

- **Autor:** Sergio Palao
- **Origen:** ARASAAC (https://arasaac.org)
- **Llicència:** Creative Commons BY-NC-SA 4.0 (https://creativecommons.org/licenses/by-nc-sa/4.0/)
- **Propietat:** Govern d'Aragó

Es redistribueixen sense modificacions, amb aquesta mateixa llicència i sense finalitat comercial. La llista i la correspondència amb les claus de l'app són a `pictograms/starter.json`. Es poden tornar a descarregar amb `npm run pictos`.
